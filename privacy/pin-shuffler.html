Pin Shuffler Privacy Policy

Pin Shuffler does not collect, store, or transmit any personal information. It has no servers, no accounts, and no analytics. Nothing it reads ever reaches the developer.

What Pin Shuffler accesses

Pin Shuffler runs only on pinterest.com. There it accesses:

  • Pin identifiers and positions. It reads the identifier and slot position of each pin on the board you are organizing, so it can work out and apply a new order.
  • Your board's identifier. Pinterest does not reliably include this in the page, so from the moment a Pinterest page loads, Pin Shuffler inspects the addresses and request bodies of Pinterest's own network requests, looking for a board identifier. It matches a single pattern and keeps only the number it finds; nothing else is read out, retained, or sent anywhere. If that does not produce an identifier, it asks Pinterest's board API for it directly, or searches the page's inline scripts for the same pattern.
  • Your Pinterest CSRF token. Pinterest requires this cookie value on any request that changes your account. Pin Shuffler reads it from the page and returns it to Pinterest with each reorder request. It is not stored and is not sent anywhere else.

What is stored on your device

Pin Shuffler uses Chrome's local extension storage, never sync storage, to save five values: your board's pin order before a shuffle, its order after a shuffle, which board that shuffle was done on (Pinterest's numeric ID for the board, used so Undo only appears on that board), whether an undo is available, and which version of the extension's change notice you have dismissed. This data stays on your device. The saved pin orders and board ID are deleted once an Undo completes, and removing the extension clears everything.

What Pin Shuffler sends

The only network requests Pin Shuffler makes are to Pinterest, over HTTPS, using your existing Pinterest session: lookups for your board's identifier, and one reorder request for each pin moved. These are the same requests Pinterest's own site makes when you drag a pin by hand, and they carry out only actions you are already signed in to perform. Data handled by Pinterest is subject to Pinterest's Privacy Policy.

There are no other network requests. Pin Shuffler contains no analytics, telemetry, crash reporting, or advertising code, and its fonts are bundled inside the extension so that opening it contacts no outside host.

Permissions

Pin Shuffler requests two permissions: storage, to save your pin order on your device, and access to https://www.pinterest.com/*. It does not request Chrome's tabs permission, so Chrome does not give it the address of any page outside Pinterest.

Limited use

Pin Shuffler uses the data it accesses only to reorder pins on your boards. That data is never sold or transferred to third parties, never used for advertising, and never seen by anyone at Innovaritas LLC, because the extension has no mechanism that could transmit it to the developer. This complies with the Chrome Web Store Limited Use policy.

Changes to this policy

If Pin Shuffler's data practices change, this policy and the date below will be updated, the Privacy Practices on its Chrome Web Store listing will be updated, and the extension will show you a notice describing the change the next time you open it.
